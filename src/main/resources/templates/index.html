About

I'm a student learning backend engineering the slow way: building small services from end to end and finding out where my design choices fall short.

Databases get most of my attention. Schema design, indexing and query behaviour decide a lot of what an API can do, and I would rather understand that layer than treat it as a black box. System design is what I'm working through next, alongside regular data structures and algorithms practice.

Generative AI is a secondary interest. I'm exploring it through Text-to-SQL, where the model has to respect a real schema and its output can be checked against a real database.
